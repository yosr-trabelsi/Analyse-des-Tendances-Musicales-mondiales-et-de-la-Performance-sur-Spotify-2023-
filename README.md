# Analyse des Tendances Musicales Mondiales et de la Performance sur Spotify (2023)

## Description

Ce projet consiste à analyser les tendances musicales mondiales et la performance des titres sur Spotify en 2023 à l'aide de Power BI.
Il s'agit du projet final réalisé dans le cadre de la certification en Data Analytics avec Power BI chez GoMyCode.

L'objectif est d'explorer les caractéristiques des morceaux les plus performants, d'identifier les tendances musicales et de mettre en évidence les facteurs associés à la popularité des titres.

## Objectifs

* Analyser les tendances musicales mondiales en 2023
* Identifier les artistes et titres les plus performants
* Étudier l'évolution et la distribution des indicateurs de performance
* Comparer les performances selon différents critères
* Créer un tableau de bord interactif permettant de visualiser les principaux résultats

## Outils utilisés

* **Power BI**
* **Power Query** — préparation et transformation des données
* **DAX** — création de mesures et indicateurs
* **Data Visualization** — création du dashboard interactif

## Analyse

Le dashboard permet notamment d'explorer :

* La popularité des morceaux
* Les artistes les plus performants
* Les caractéristiques musicales des titres
* Les indicateurs de performance sur Spotify
* Les tendances et comparaisons entre différentes catégories
